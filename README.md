# Prediction of Agriculture Crop Production in India

## Dataset
- Source: [data.gov.in](https://data.gov.in)
- Years: 2001–2014
- Columns: Crop, Variety, State, Quantity, Production, Season, Unit, Cost, Recommended Zone

## Goals
- Analyze crop production trends
- Build ML models to predict future production
- Provide insights for farmers and policymakers
